# ADR-0054: Support Claude Fable 5.2 through the bundled CLI

## Status

accepted

## Context

Claude Fable 5.2 was released on November 9, 2026. ADR-0052 advertises only current model generations. Fable 5.2 requires Claude Code 2.1.321 or later; the provider's pinned Agent SDK 0.3.283 bundles an older CLI.

## Decision

- Replace Fable 5.1 in the eight advertised presets with `claude-fable-5-2`. Default its effort to `medium`, the Claude Code default, rather than the Claude API default of `high`. Explicit effort still wins; provider defaults stay unchanged.
- Keep explicit Fable 5.1 configurations at their historical `low` effort and retain their pricing. Saved invocation price catalogs remain authoritative.
- Register Fable 5.2's standard USD/MTok rates: input 8, output 40, cache read 0.20, and 5-minute cache write 10. Do not infer aliases or rates for other models.
- Add Fable 5.2 to the existing cache-preserving effort-change allowlist. Keep the CLI/environment guards and require matching concrete models from both preflight calls. A model change still starts a new session.
- Override only the Claude provider's Agent SDK dependency to 0.3.321, which bundles Claude Code 2.1.321. Updating a CLI on PATH does not update the binary this factory runs. Revisit the override when the provider updates its pinned dependency.
- Continue letting the Agent SDK manage conversation history. The migration guide says the stricter thinking-prefix check needs no changes for SDK-managed histories. This factory does not construct API message arrays or use the advisor or computer-use tools affected by the other migration changes.

## Validation

Tests cover preset effort, historical Fable 5.1 behavior, price parsing and all cache legs, invocation catalogs that predate Fable 5.2, strict model matching, and preflight confirmation of the model used for effort-change continuation. The installed SDK reports Claude Code 2.1.321. A read-only minimal provider call returned `OK` and reported `claude-fable-5-2` at resolved `medium` effort. Account access remains subject to runtime preflight.
