# Web UI

[README](../README.md) に戻る。

```bash
pnpm factory ui
pnpm factory ui --port 4500
```

起動後に表示される URL（デフォルト `http://127.0.0.1:4380/`）をブラウザで開きます。`127.0.0.1` のみで待ち受け、CLI と同じ SQLite DB を 3 秒ごとにポーリングします。`DURABLY_FACTORY_STATE_DIR` を変えている場合は、UI を起動するターミナルにも同じ環境変数を設定してください。

Web UI 自体はワーカーを起動しません。画面から承認や再実行を行ったあとに処理が進まない場合は、[ワーカーの稼働状態](operations.md#ワーカーのライフサイクル) を確認してください。

## タスク一覧と操作

| セクション     | 表示される内容                                                                           |
| -------------- | ---------------------------------------------------------------------------------------- |
| 判断待ち       | 候補の承認や仕様の判断など、人のアクションを待っているタスク                             |
| 動いているもの | 実行中の工程と経過時間、順番待ち、ワーカー再開待ちのタスク                               |
| 止まったもの   | 停止理由と次に実行できる操作（不要になった停止はチェックボックスから一括アーカイブ可能） |
| 終わったタスク | 最終結果と親・子 run の履歴（「アーカイブ済みも表示」でアーカイブ済みタスクも閲覧可能）  |

- 複数リポジトリを扱っている場合は、一覧と集計をリポジトリ単位でフィルタできます。
- 各操作ボタンの下にある「同じ操作の CLI コマンド」を開くと、同等の操作を行う CLI コマンドをコピーできます。画面からの再実行は保存済みの入力を使うため、`factory.json` を読み直したい場合は CLI の `retrigger --reload-config` を使ってください。

## 実行の詳細と集計タブ

- **実行の詳細**: タスク名や各 run を開くと、工程のタイムライン、各ステージの所要時間・コスト、検証やレビューの詳細を確認できます。行を選択するとエージェントの出力や `check` の stdout/stderr ログをリアルタイムで追跡できます（長いログは末尾 256 KiB を表示するため、全文は表示されたパスをコピーして確認してください）。
- **集計**: 「週ごとの推移」（`compare --trend` 相当）と「設定ごとの比較」（`compare --runs` 相当）を切り替えられます。集計の仕様は [計測・レポート・比較](measurement.md) と同じです。

## デモデータと UI コンポーネント確認

DB やワーカーを用意せず UI の見た目だけ確認したい場合は、`http://127.0.0.1:4380/#/design` を開きます。実際の運用に近いデータで画面と操作を試したい場合は、`seed` コマンドで一時ディレクトリにデモ環境を構築できます。

```bash
pnpm factory seed
pnpm factory seed --home ~/tmp/factory-demo --latency 3000-15000
```

`seed` は普段の `~/.local/state/durably-factory/` に一切触れず、一時ディレクトリ（`--home` 指定時は空または未作成のパス）にサンプルリポジトリと複数の `fake` 実行データを作成します。完了後、その環境用の `ui` 起動コマンドとワーカー情報が表示されます（`--latency` は 1 回の模擬呼び出しにかかる時間範囲をミリ秒で指定します）。
