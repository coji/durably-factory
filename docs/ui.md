# ブラウザで見る（web UI）

[README](../README.md) に戻る。

```bash
pnpm factory ui
pnpm factory ui --port 4500
```

表示された URL を開きます。既定は `http://127.0.0.1:4380/` です。画面は CLI と同じ実行データを 3 秒ごとに読みます。`DURABLY_FACTORY_STATE_DIR` を使っている場合は、UI を起動するターミナルにも同じ値を指定します。

画面はワーカーとは別に動きます。承認や再実行の操作を送ったあとに処理が進まなければ、[ワーカーの状態](operations.md)を確認してください。

## タスク一覧

| 表示           | ここで見ること                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| 判断待ち       | 候補を承認するか、仕様を直すかなど、いま求められている判断。                                             |
| 動いているもの | 現在の工程や経過時間。順番待ちや、ワーカーの再開を待つ実行も含みます。                                   |
| 止まったもの   | 停止の理由と、再実行など次にできる操作。不要になった停止はまとめてアーカイブできます。                   |
| 終わったタスク | 最終結果と、元の実行や追加修正の履歴。「アーカイブ済みも表示」を選ぶとアーカイブしたタスクも表示します。 |

複数のリポジトリがある場合は、一覧と集計をリポジトリで絞り込めます。操作欄の「同じ操作の CLI コマンド」から、同じ操作をターミナルで実行するコマンドをコピーできます。画面からの再実行は保存済みの入力を使います。現在の `factory.json` を読み直す場合は CLI の `retrigger --reload-config` を使います。

## 実行の詳細

タスク名や個別の実行を開くと、次にできる操作、各工程の時間、検査とレビューの結果を確認できます。工程を開くと、試行ごとのエージェント出力や検査ログを読めます。長いログは末尾 256 KiB を表示するので、全文が必要なときは表示されたパスからファイルを開きます。

## 集計

「週ごとの推移」と「設定ごとの比較」を切り替えられます。元の実行と追加修正を含むタスク全体の所要時間や費用は、タスク一覧や詳細で確認できます。レポートの集計条件と読み方は [計測とレポート](measurement.md) を参照してください。

## デモデータ

画面だけを見たいときは `http://127.0.0.1:4380/#/design` を開きます。操作の流れも試したいときは、模擬実行でデータを作れます。

```bash
pnpm factory seed
pnpm factory seed --home ~/tmp/factory-demo --latency 3000-15000
```

既定では一時ディレクトリに専用の `HOME` を作ります。`--home` を指定する場合は、空のディレクトリか、まだ存在しないパスを渡します。承認待ちや検査失敗などのデータを fake プロバイダーで作り、最後にデモ用の UI を開くコマンドとバックグラウンドのワーカー情報を表示します。`--latency` は 1 回の模擬呼び出しにかかる時間の範囲で、単位はミリ秒です。
